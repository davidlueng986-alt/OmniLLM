# ADR-007 — 不受信任加速執行使用 different package/UID

## Context
Same-UID native code 可讀寫 app-private state／使用該 UID 的能力。

## Decision
不受信任加速執行使用 different package/UID。

## Alternatives considered
- 同 UID remote process
- 只靠不注入 secret

## Consequences
- 需 optional companion 與窄 IPC
- 仍有 kernel/driver/DoS residual risk

## Security／Resource／Compatibility
- 受影響的 trust、resource、identity、state 或 wire semantics 必須由 authority catalog 表達；adapter 不得建立私有例外。
- 變更若改 public／persistence／security major semantics，需 protocol/schema major version。

## Validation
- Repository validator 確認 authority／reference 無漂移；
- 對應 quality/security scenario 在實作期產生 evidence；
- Fault／negative test 必須覆蓋本決策要解決的失敗邊界。

## Reopen triggers
- Android 提供可驗證等價隔離
- companion 無法承載必要 backend

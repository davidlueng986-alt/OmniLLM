# ADR-009 — Trust、compatibility、performance、license、placement 分離

## Context
Dry-load／benchmark 不能證明來源安全，授權接受也不等於可執行。

## Decision
Trust、compatibility、performance、license、placement 分離。

## Alternatives considered
- 單一 verified flag
- 按 engine success 提升 trust

## Consequences
- 避免錯誤 privilege promotion
- UI 需投影多維狀態

## Security／Resource／Compatibility
- 受影響的 trust、resource、identity、state 或 wire semantics 必須由 authority catalog 表達；adapter 不得建立私有例外。
- 變更若改 public／persistence／security major semantics，需 protocol/schema major version。

## Validation
- Repository validator 確認 authority／reference 無漂移；
- 對應 quality/security scenario 在實作期產生 evidence；
- Fault／negative test 必須覆蓋本決策要解決的失敗邊界。

## Reopen triggers
- trust evidence model 改變
- 法規／供應鏈模型要求新維度

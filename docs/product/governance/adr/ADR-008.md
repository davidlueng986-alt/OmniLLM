# ADR-008 — Blob／ArtifactPackage／ModelRevision／Installation 分層

## Context
Raw bytes、package role、可執行語義與安裝實例是不同 identity。

## Decision
Blob／ArtifactPackage／ModelRevision／Installation 分層。

## Alternatives considered
- 單一 model_hash
- 以檔名／URL 作 identity

## Consequences
- 去重／撤銷／license 語義清楚
- 需要 canonical encoding/versioning

## Security／Resource／Compatibility
- 受影響的 trust、resource、identity、state 或 wire semantics 必須由 authority catalog 表達；adapter 不得建立私有例外。
- 變更若改 public／persistence／security major semantics，需 protocol/schema major version。

## Validation
- Repository validator 確認 authority／reference 無漂移；
- 對應 quality/security scenario 在實作期產生 evidence；
- Fault／negative test 必須覆蓋本決策要解決的失敗邊界。

## Reopen triggers
- identity formula major change
- 新 format 無法映射現有層級

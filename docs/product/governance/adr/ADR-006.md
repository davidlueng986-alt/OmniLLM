# ADR-006 — SSE stateless-by-default；AIDL application ACK

## Context
Socket write completion 不能證明 client application 已消費；Binder oneway 也不等於消費。

## Decision
SSE stateless-by-default；AIDL application ACK。

## Alternatives considered
- 將 write completion 當 delivered
- 永久保存所有 SSE token

## Consequences
- SSE 斷線 Session 不自動續用
- AIDL 需 credit/final ACK

## Security／Resource／Compatibility
- 受影響的 trust、resource、identity、state 或 wire semantics 必須由 authority catalog 表達；adapter 不得建立私有例外。
- 變更若改 public／persistence／security major semantics，需 protocol/schema major version。

## Validation
- Repository validator 確認 authority／reference 無漂移；
- 對應 quality/security scenario 在實作期產生 evidence；
- Fault／negative test 必須覆蓋本決策要解決的失敗邊界。

## Reopen triggers
- 新增 application-level HTTP ACK/resume
- delivery semantics major change

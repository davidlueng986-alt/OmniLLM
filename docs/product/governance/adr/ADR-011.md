# ADR-011 — HTTP／AIDL／Admin 共用 canonical semantics

## Context
統一平台需要同一 request/event/error；transport 只保留 delivery/encoding 差異。

## Decision
HTTP／AIDL／Admin 共用 canonical semantics。

## Alternatives considered
- 各 transport 獨立 API
- 最低共同分母

## Consequences
- 降低 client/engine 語義漂移
- 需 formal schema/codegen

## Security／Resource／Compatibility
- 受影響的 trust、resource、identity、state 或 wire semantics 必須由 authority catalog 表達；adapter 不得建立私有例外。
- 變更若改 public／persistence／security major semantics，需 protocol/schema major version。

## Validation
- Repository validator 確認 authority／reference 無漂移；
- 對應 quality/security scenario 在實作期產生 evidence；
- Fault／negative test 必須覆蓋本決策要解決的失敗邊界。

## Reopen triggers
- transport 需要不可映射的核心語義
- canonical major version

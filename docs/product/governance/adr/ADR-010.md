# ADR-010 — Runtime control plane 為 single writer

## Context
多 process 同寫 DB／resource state 難以提供 transaction／recovery。

## Decision
Runtime control plane 為 single writer。

## Alternatives considered
- Room/DataStore 多 writer
- eventual consistency

## Consequences
- 所有 mutation 經 narrow commands
- Runtime 可成 bottleneck，需非阻塞設計

## Security／Resource／Compatibility
- 受影響的 trust、resource、identity、state 或 wire semantics 必須由 authority catalog 表達；adapter 不得建立私有例外。
- 變更若改 public／persistence／security major semantics，需 protocol/schema major version。

## Validation
- Repository validator 確認 authority／reference 無漂移；
- 對應 quality/security scenario 在實作期產生 evidence；
- Fault／negative test 必須覆蓋本決策要解決的失敗邊界。

## Reopen triggers
- 平台改為外部 transactional service
- single writer 無法滿足可用性

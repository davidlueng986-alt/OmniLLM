# Package contents

本 ZIP 僅包含現行產品、體驗、架構、功能、引擎、平台、治理與 canonical machine-readable 設計。

包含：

- 110 份具穩定文件 ID 的來源設計文件；
- 1 份連續閱讀總綱；
- 31 份 YAML authority／catalog／contract；
- SQLite schema；
- 3 份設計模板；
- repository index、SHA-256 manifest 與兩個可重跑維護驗證器。

不包含：FSM audit、finding closure、歷史稽核報告、稽核輸入快照、實機 benchmark、AAB、程式碼或 qualification 假證據。
